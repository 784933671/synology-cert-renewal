# 证书管理界面风格预览

打开 `index.html`，选择三套风格：A DSM 经典、B 简洁工作台、C 深色监控台。也可以在当前目录运行 `python3 -m http.server 18863 --bind 127.0.0.1`，浏览器访问 `http://127.0.0.1:18863`。

三套页面共享功能和示例数据，包括运行概览、证书管理、续期计划、邮件通知、运行记录、访问安全和登录页。可以保存预览设置、查看失败详情、切换空状态。修改只保留在当前页面内存，刷新恢复默认。

这是用于选择视觉方向的原型，不包含服务端、实际登录验证、真实邮件发送或 NAS 操作。凭据输入禁用，禁止填写真实密码或密钥；访问安全页展示后续实施目标，不能作为网络隔离已经生效的证明。

选定风格后再实现正式 Vue 页面、Docker 管理服务和内网访问控制。现有群晖任务不受预览影响。
