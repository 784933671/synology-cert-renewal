# Docker 管理层部署验收

记录日期：2026-11-03，Asia/Shanghai。

## 已部署

- 设备：DS218+，DSM 7.3.1-86003 Update 1，Docker 24.0.2。
- 管理目录：`/usr/local/share/synology-cert-web`；容器：`synology-cert-web`。
- 管理入口：`https://ttxli.cn:18443`，IPv4 监听 `10.10.10.37:18443`，未监听 IPv6。
- 管理账号 `admin`，用户在私有终端自行设置初始密码；首次网页登录要求修改。临时验收密码已撤销、临时凭据文件已删除，旧会话数为零。
- 开机入口：`/usr/local/etc/rc.d/S99synology-cert-web.sh`。原任务 7 继续执行续期，管理容器没有第二套续期定时器。
- 容器使用 UID/GID 10100、只读根文件系统、移除全部 capability、禁止提权，绑定逻辑 CPU 0，内存 384 MiB，非 root 用户进程数上限 96，每进程打开文件数上限 1024。该 DSM 内核不支持 CFS 配额及 PID cgroup，因此使用 cpuset 和 ulimits。
